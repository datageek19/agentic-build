Which Component to Use (WebFrameSrcdoc vs WebFrameUrl) 

 

Use the WebFrameSrcdoc component if you don’t need network access, are building simple/lightweight widgets, want to channel all bi-directional UI interactions through your agent, and don’t want to worry about hosting/deployment of frontend code. This path also allows you to neatly manage context and interactions with your agent through one channel.
